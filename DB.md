# Database & Storage Structure

This document outlines the schema and organization of data persisted by the SGD-Mini RAG Pipeline.

## 1. PostgreSQL (Structured Data)

The pipeline uses PostgreSQL for storing high-level technical summaries and extracted QA pairs.

### Schema: `knowledge_base`
Stores detailed, long-form technical summaries generated by the LLM for each document.

| Column | Type | Description |
|--------|------|-------------|
| `id` | SERIAL | Primary key. |
| `source_file` | TEXT | The name of the original markdown file. |
| `content` | TEXT | The detailed technical summary of the document. |
| `created_at` | TIMESTAMP | Automated timestamp of insertion. |

### Schema: `qas`
Stores extracted Question-Answer pairs for fine-tuning or RAG evaluation.

| Column | Type | Description |
|--------|------|-------------|
| `id` | SERIAL | Primary key. |
| `source_file` | TEXT | The name of the original markdown file. |
| `question` | TEXT | The extracted question. |
| `answer` | TEXT | The corresponding concise answer. |
| `created_at` | TIMESTAMP | Automated timestamp of insertion. |

---

## 2. SeaweedFS / MinIO (Object Storage)

The pipeline uses SeaweedFS (via its S3 compatibility layer) for raw file backups and artifact storage.

### Directory / Bucket Structure

| Bucket Name | File Name | Format | Description |
|-------------|-----------|--------|-------------|
| `rag-kb` | `knowledge_base.json` | JSON | Structured list containing technical summaries and filenames. |
| `rag-qa` | `qas.json` | JSON | A structured list of all extracted Question-Answer pairs. |

### Accessing the Filer
SeaweedFS provides a visual browser called the **Filer UI**. You can explore the `/buckets/` path to see these files:
- **Service Name**: `minio-service` (target port 8888)
- **URL**: `http://localhost:8888/buckets/`

---

## 3. Data Flow
1. **Source**: Markdown files are ingested from `/mnt/data`.
2. **Processing**: LLM generates summaries and QAs.
3. **Persistence**:
   - `storage-op` connects to `postgres-service:5432`.
   - `storage-op` connects to `minio-service:9000` (S3 API).
